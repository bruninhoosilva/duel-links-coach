# Duel Links Coach

A beginner-friendly guide to Yu-Gi-Oh! Duel Links decks: which cards work together, a step-by-step play order with the skill built in, real deck lists, where to get each card, and a hand picker.

Unofficial fan tool, not affiliated with Konami. Yu-Gi-Oh! card names, text and artwork belong to Konami and are shown only as a reference for the guides. Card text and deck statistics come from Duel Links Meta; card pictures come from YGOPRODeck. Each guide is written in our own words from the creators' videos (credited on the deck page).

If you are a rights holder and want something removed, open an issue.
